# Fuentes propias y piezas comunes en components.css

Categoría: css · Afecta: [diseno](../diseno/)

## Qué

- Las fuentes (Hanken Grotesk 300, 400 y 600; Inter 400, 500 y 600) se sirven desde `public/assets/fonts/` con `@font-face` en `src/css/fonts.css`, con `font-display: swap`.
- Las piezas que se repiten en todas las páginas van en `src/css/components.css`, dentro de `@layer components`, con nombres de clase en inglés: `.wrap`, `.btn` y sus variantes, `.field`, `.field-input`, `.check`, `.nav-link`, `.menu-pill`, `.menu`, `.icon` y `.toast`.
- `theme.css` añade los tokens `--text-subtitle`, `--text-subtitle-mobile`, `--text-small` y `--text-eyebrow`, con valores de la web entregada.

## Por qué

Sin archivos de fuente, el texto salía en Helvetica o Arial. Se sirven desde el propio servidor y no desde Google Fonts, para que no salgan datos del visitante hacia terceros. Hanken Grotesk sigue siendo la sustituta de Agrandir.

Las piezas comunes llevan clases propias porque, con solo utilidades de Tailwind, un botón repetiría quince utilidades en cada uso. Las clases siguen `DESIGN.md` y no el boceto: botones de 45 px, campos de 40 px con esquina de 4 px, foco de 2 px y formulario sobre harina. Todo es mobile first y solo usa tokens. Las animaciones de CSS (la entrada del menú y el aviso) solo se aplican con `prefers-reduced-motion: no-preference`.

## Archivos

- `src/css/fonts.css` — `@font-face` de las seis fuentes
- `src/css/components.css` — piezas comunes y reglas base
- `src/css/theme.css` — tokens nuevos de tamaño de texto
- `src/css/main.css` — importa las dos hojas nuevas
- `public/assets/fonts/` — archivos `.woff2` y licencias OFL
