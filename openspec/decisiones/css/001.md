# Tailwind v4 compilado con un tema único

Categoría: css · Afecta: [diseno](../diseno/)

## Qué

Tailwind se compila con su CLI (`npm run build`) a `public/assets/css/styles.css`, que no se versiona. `src/css/main.css` importa `theme.css`, que vacía las paletas y escalas por defecto de Tailwind y deja solo los tokens de ERD. Solo existen los puntos de corte `sm` y `lg` de la web, con enfoque mobile first.

## Por qué

La versión por CDN no lee un `@theme` enlazado y la documentación oficial la limita a desarrollo. Vaciar la paleta por defecto evita colores fuera de marca. Se comprobó la compilación con la CLI 4.1.11. Al vaciar los radios dejó de existir `rounded-md`, y por eso el botón de envío usa el token propio `--radius-submit`.

## Archivos

- `package.json` y `package-lock.json` — la CLI de Tailwind fijada en la versión 4.1.11
- `src/css/main.css` — entrada del CSS
- `src/css/theme.css` — tokens
