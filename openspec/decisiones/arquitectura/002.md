# Despliegue por FTPS con GitHub Actions

Categoría: arquitectura · Afecta: [html](../html/), [php](../php/)

## Qué

Cada push a `main` comprueba la sintaxis de PHP, ejecuta las pruebas, compila el CSS y sube por FTPS primero `src/` (a la carpeta superior de la carpeta web) y después `public/` (a `FTP_REMOTE_DIR`), sin `--delete`. Mientras la portada pública sea «Properament», no se suben `index-v2.html` ni `contact.php`.

## Por qué

El hosting solo ofrece FTP. El CSS compilado no se versiona y se genera en el despliegue. Subir `src/` antes que `public/` evita dejar la web a medias si falla la primera subida, y no usar `--delete` protege el `.env` del servidor. El certificado se verifica. Alternativas descartadas: GitHub Pages (no ejecuta PHP y exigía un repositorio público) y compilar en local subiendo el CSS (ensucia el historial).

## Archivos

- `.github/workflows/deploy.yml` — el flujo de comprobación, compilación y subida
