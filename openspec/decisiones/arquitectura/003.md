# Despliegue manual por FTP, sin GitHub Actions

Categoría: arquitectura · Afecta: [css](../css/), [php](../php/) · Sustituye: [002](002.md)

## Qué

Se elimina el despliegue automático. Pau sube la web a producción a mano por FTP: `public/` a `/web` y `src/` a la raíz del FTP, tras ejecutar `npm run build` y `php tests/run.php` en local. Ya no hay Secrets de GitHub.

## Por qué

El primer despliegue falló con `ftp:ssl-force is set and server does not support or allow SSL`. Se comprobó que el servidor (ProFTPD) responde `500 AUTH not understood` y no ofrece FTPS. Subir por FTP sin cifrar desde un ejecutor de GitHub expondría la contraseña y los archivos en internet, así que se descartó. GitHub Pages también se descartó: exigiría repositorio público o un plan de pago, y rompe las rutas absolutas. Con el despliegue a mano, la subida pasa por el equipo de Pau, y el CSS compilado sigue sin versionarse porque se compila en local antes de subir.

La subida sigue siendo FTP sin cifrar. Queda pendiente pedir al hosting que active TLS.
