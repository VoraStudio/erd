# El boceto HTML es una idea; mandan DESIGN.md y las reglas

Categoría: diseno · Afecta: [arquitectura](../arquitectura/)

## Qué

El HTML entregado por VoraStudio (`sdd-local/brand/ERD/02 Web/`) es un boceto: aporta la estructura de las páginas, los contenidos y los efectos, pero no es el resultado que hay que copiar. El orden de precedencia es `DESIGN.md` y `theme.css`, después las reglas de `AGENTS.md` y, en último lugar, el boceto. La web se construye mejor que el boceto.

## Por qué

Lo decide Pau tras estudiar el boceto. Su CSS es desktop first, repite el logotipo en línea tres veces por página (el 74 % del peso de la Home), mete encabezados dentro de botones, no tiene `<main>`, usa `href="#"` y pone las fotos como fondos CSS sin texto alternativo. Copiarlo tal cual iría contra las reglas del proyecto. La regla anterior («sin reinterpretar el diseño») hacía del boceto la autoridad y queda sustituida.
